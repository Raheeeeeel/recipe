"# Recipe Table

## Run locally

Open this project folder in a terminal and run:

```powershell
node server.js
```

Then open `http://localhost:3000` in your browser. Keep the terminal open while using the app. The server creates `recipes.json` if it is missing or empty, and each new recipe is written to that file. Use the **View the saved recipes.json** link on the page to inspect the current JSON.

Do not open `index.html` directly or use a static preview server: browsers cannot write submissions to the project's JSON file."
